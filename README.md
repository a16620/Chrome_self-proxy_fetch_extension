# Chrome-API-self-proxy-extension
CORS 우회를 위한 익스텐션 기반의 fetch 호출기. 스크립트를 수정하므로 위험한 동작이 일어날 수 있으므로 주의해야함. 이 프로그램은 개발용이고 모든 책임은 사용자에게 있음.    

# 이용 방법
## 설치
크롬의 "확장프로그램" > "확장프로그램 관리" > "개발자 모드" on > "압축해제된 확장프로그램 로드" 선택 > 다운로드된 폴더 선택    
보안상의 이유로 제한된 사이트의 CORS만 통과된다. **manifest.json의 host_permissions을 수정해 추가할 수 있다**.    
마찬가지로 프로그램은 로컬 파일(file:///*)에서만 실행되도록 manifest.json에 설정되어 있다.

## 화이트 리스트 설정
'file:///'으로 시작하는 경로에서 메뉴를 열면 사진의 '이 페이지는 등록할 수 없습니다.' 대신 추가 버튼이 있다. Content-script는 'file:///*'에 대해 모두 실행되지만 화이트 리스트에 없는 경우 동작을 멈추게 된다.

## 모드 설정
작동 방식은 확장 프로그램에서 등록한 fetch를 호출하면, 먼저 기본 fetch를 호출하고 결과에 오류가 있으면 그때 확장 프로그램에 요청을 보내게 된다.

### 코드에 추가해야 하는 것
아래의 메타 태그를 넣으면 확장 프로그램이 문서를 로드할 때 인식해 fetch를 등록한다.
```html
<meta name="api-helper" content="enable">
```

### 추가 fetch 등록 모드(안전)
별도의 공간을 만들어 fetch를 등록한다. 그 fetch를 이용해 이 프로그램에 요청할 수 있다.    
myAPI 같은 저장되는 이름은 메뉴에서 '네임스페이스'로 지정 가능.    
```javascript
myAPI.fetch(URL, {method: 'GET'})
```

### 오버라이딩 모드(**!!위험!!**)
기존에 있는 전역 함수 fetch를 덮어쓴다. 이 함수는 기존의 fetch 호출 후 오류 발생 시 확장 프로그램의 fetch를 호출한다.   
코드 변경 없이 이용 가능하지만 **보안이나 여러 예측할 수 없는 위험한 동작을 일으킬 수 있다.**  
```javascript
fetch(URL, {method: 'GET'})
```
